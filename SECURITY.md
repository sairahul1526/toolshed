# Security policy

Please **don't open a public issue** for a security problem.

Report it privately through GitHub instead: on this repo's **Security** tab, choose **Report a vulnerability**. Include:

- what the problem is and where it is (file, route or screen);
- the steps to reproduce it;
- what an attacker could do with it.

We'll reply within 7 days and keep you updated until it's fixed. With your permission, we'll credit you in the release notes.

## Supported versions

Toolshed is pre-alpha and has no releases yet. Fixes go to `main`.
