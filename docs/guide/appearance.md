# Change how Toolshed looks

Open **Appearance** in the dashboard menu. Owners and admins can change it. Everyone else can look at it but not change it.

## What you can set

**Dashboard**
- **Mode**: System follows each person's device. Light and Dark stay fixed.
- **Accent**: the colour used for buttons and highlights. Each colour has a name, so you never have to rely on colour alone.

**Public pages** (forms, link pages and anything else visitors see)
- **Look**: Paper, Warm, Cobalt or Dusk. Each has a light and a dark version, and visitors get the one their device uses.
- **Powered by Toolshed**: a small link at the bottom of public pages. It is optional.

**Logo**
- Paste the web address of your logo. It must start with `https://` and point to a public site. Toolshed uses it in the emails it sends from your workspace. Uploading a file is not available yet.

## Preview

The preview at the top shows your dashboard and a public page with the values that are saved right now. Change something, choose **Save appearance**, and the preview updates.

## Workspace default and "just for me"

What you save here is the workspace default, so it applies to everyone. People can still pick their own light or dark mode for themselves with the theme button in the dashboard. That choice stays in their browser and does not change anyone else's view.

## Reset to defaults

**Reset to defaults** puts the mode, accent, public page look and the Powered by Toolshed line back to the Toolshed defaults, and removes the logo address. It asks you to confirm first. You can set everything again at any time.

## Who changed it

Every save is written to the audit log as `appearance.updated`, with the names of the settings that changed and who changed them.
